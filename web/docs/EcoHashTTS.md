# EcoHash TTS

Configure the **public** key, choose a speech model and enter text and a supported voice ID.
When the catalog supplies `voices`, **Choose voice** lists those values. Otherwise consult
the model's documentation and type the ID. Voice IDs are not interchangeable across models;
the Kokoro default `af_bella` is cleared when switching to another model without a voice list.

Connect `AUDIO` to Preview Audio or Save Audio. This node uses the public API.
