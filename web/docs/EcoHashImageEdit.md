# EcoHash Image Edit

Configure the **public** key using **Connections**. Connect a single `IMAGE`, select an
edit-capable public model and enter an editing instruction. `size=auto` sends the input
image dimensions; the service may round them. `custom` reveals explicit dimensions.

This is a complete remote image-edit operation. Only parameters exposed by the API are
available. For a private deployment use **EcoHash Dedicated Image Edit**.
